# Task: Empty Name Validation

## 1. Feature Overview
- **Sprint:** `sprint-greeting`
- **Target Route:** `/`
- **User Story:** As a user, if I submit an empty name field, I should see an error alert instructing me to enter a name first.

## 2. Acceptance Criteria
- [x] Submitting empty name triggers an alert role element.
- [x] Alert text reads 'Enter a name first.'.
- [x] Alert message is styled prominently in warning colors.
